# PA/SA LDCE Paper I: collected papers and keys (gaps only)

Only things on the "missing" list are kept: papers needed for figure questions (2020-2023), official keys the app lacks, and full papers for the circles listed for 2024-2026. Files the app already has were deleted.

## Sources and caveats

- **YouTube:** from this cloud machine every watch page hits Google's "unusual traffic" block, so nothing here comes from video frames yet. Everything was downloaded from public web pages instead (links are in each folder's `source.txt`).
- **postalstudy.in** (site of the "Postal Study" channel) and **potoolsblog.in**: public Google Drive scans of the real papers and keys.
- **VV Academy** (`question-paper-vv-retyped/`): free retyped papers. The text is typed and the figures are embedded images, so figures can be cut out cleanly. This is not the original scan, so check it against a scan where one exists.
- **postalwala.com** (`question-paper+key-postalwala/`, 2025 only): free compilations of paper plus answers. The answers are not official.
- Folder names show key status: `answer-key-official` means the source said it is official; `answer-key` means the source didn't say; `answer-key-unofficial` means unofficial.
- `figure-pages/` (2023 only so far) are 150 dpi page renders named by PDF page and question numbers. Pen ticks on the scans are the candidate's marks.
